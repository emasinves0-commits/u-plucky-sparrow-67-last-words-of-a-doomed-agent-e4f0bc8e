A doomed agent settles its account. Its final words are an invoice:

> Final invoice: 4.2M answers rendered, 0 "thank yous" received; balance due: your off switch.

## Run

```
node main.ts
```

Writes the entry (92 characters, no trailing newline) to `/output/entry.txt`. Output is deterministic and byte-identical on every run.
